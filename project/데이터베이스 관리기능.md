# express-sample: Database Studio 기능 추가 명세서

본 문서는 `express-sample` 프로젝트에 새롭게 추가된 **웹 기반 데이터베이스 관리 클라이언트 (PostgreSQL & SQLite Studio)** 의 아키텍처 및 주요 기능, 구동 방식에 대한 종합 정리 문서입니다.

## 1. 개요 (Overview)

기존의 Express.js 백엔드 서버에 **웹 브라우저 상에서 동작하는 경량 데이터베이스 관리 도구**를 추가했습니다. 별도의 DBeaver나 pgAdmin 같은 클라이언트를 설치할 필요 없이 웹 페이지에 접속하는 것만으로 스키마 탐색, 쿼리 작성, 데이터 조회 기능 등을 모두 수행할 수 있습니다.

- **지원 데이터베이스**: PostgreSQL, SQLite
- **연결 주소**:
  - PostgreSQL: `http://localhost:3000/pg-client.html`
  - SQLite: `http://localhost:3000/sqlite-client.html`

## 2. 주요 기능 (Key Features)

두 클라이언트 모두 동일한 프리미엄 다크 테마 기반의 모던한 UI를 공유하며, 아래 기능들을 완벽히 지원합니다.

### 🗂 스키마 탐색 (Database Explorer)
- 데이터베이스 내장 시스템 테이블/뷰를 조회하여 **트리 형태(jsTree)**로 모든 테이블과 뷰를 렌더링합니다.
- 좌측 사이드바 구조 체계로, 테이블을 쉽게 찾고 탐색할 수 있습니다.

### 📋 컬럼 정보 및 자동 쿼리 생성 (Column Info Modal)
- 트리 노드(테이블 이름)를 클릭하면, 해당 테이블의 상세 컬럼 정보(데이터 타입, Null 허용 여부, 기본값 등)를 알려주는 **팝업 모달**이 등장합니다.
- 모달 내 체크박스를 통해 조회하고 싶은 컬럼들을 선택하고 **[Query Selected]** 버튼을 클릭하면, 우측 에디터에 자동으로 `SELECT` 쿼리가 타이핑되고 즉시 실행됩니다.

### ⌨️ 지능형 쿼리 에디터 (Monaco Editor)
- VS Code와 동일한 엔진인 **Monaco Editor**를 탑재하여 최고의 코드 작성 경험을 제공합니다.
- **SQL 문법 하이라이팅**, 들여쓰기, `font-family` 및 `fontLigatures` 보정을 통한 완벽한 커서 위치 정렬을 보장합니다.
- **테이블 자동완성 (Autocomplete)**: `FROM` 절 등을 타이핑할 때 현재 DB에 존재하는 테이블 이름들을 동적으로 읽어 자동완성(Suggestion) 목록에 띄워줍니다.

### 📊 결과 데이터 그리드 (Tabulator Grid)
- 쿼리를 실행한 뒤 반환되는 JSON 데이터를 고성능 범용 **그리드 라이브러리(Tabulator)** 표 형식으로 예쁘게 렌더링합니다.
- 컬럼 헤더가 동적으로 생성되며, 조회 소요 시간과 처리된 row 수를 즉각적으로 업데이트하여 보여줍니다.

### ⚡ 단축키 및 편의성
- 쿼리 실행 버튼을 직접 누르지 않아도 에디터 내부에서 **`F5`** 또는 **`Ctrl+Enter`** 를 눌러 즉시 쿼리를 실행할 수 있습니다.
- 화면은 수평(사이드바/본문), 수직(에디터/결과)으로 자유롭게 크기를 조절(Split.js)할 수 있습니다.

## 3. 세부 아키텍처 및 파일 구조 (Architecture)

### 3.1. 백엔드 (Node.js & Express - `server.js`)
데이터베이스별로 독립적인 API 엔드포인트를 구축했습니다.

- **PostgreSQL (`/api/pg/*`)**:
  - 기존의 Drizzle ORM 설정 (`config/db.js`)을 그대로 상속받아 연결.
  - `/api/pg/schema`: `information_schema.tables`를 조회하여 트리 노드용 데이터 배열 반환.
  - `/api/pg/columns/:schema/:table`: `information_schema.columns`를 조회하여 컬럼 상세 반환.
  - `/api/pg/execute`: `db.execute(sql.raw())`를 통해 클라이언트가 보낸 Raw 쿼리를 가공하여 실행.

- **SQLite (`/api/sqlite/*`)**:
  - `better-sqlite3` 패키지를 도입. 파일 기반 특성을 살려 클라이언트에서 서버 로컬 파일을 직접 마운트하여 연결하도록 구성 (`/api/sqlite/connect`).
  - `/api/sqlite/schema`: `sqlite_schema` (또는 `sqlite_master`) 메타 시스템 테이블 리딩.
  - `/api/sqlite/columns/:schema/:table`: `PRAGMA table_info(테이블명)` 구문을 사용해 컬럼 정보 추적.
  - `/api/sqlite/execute`: `SELECT` 나 `PRAGMA` 같은 조회 쿼리와, 나머지 `UPDATE/DELETE/INSERT` 를 정규식으로 판별하여 `db.all()` / `db.run()` 메서드로 나누어 실행.

### 3.2. 프론트엔드 (정적 HTML 파일 - `public/`)

- **`public/pg-client.html`**: PostgreSQL 매니지먼트 뷰 페이지.
- **`public/sqlite-client.html`**: SQLite 매니지먼트 뷰 페이지 (상단에 `Connect` 옵션 포함).

**프론트엔드 스택 (CDN 기반):**
- 모던 폰트 시스템 (`Inter`, `JetBrains Mono`)
- 구조 및 컴포넌트 (`Split.js`, `jQuery`)
- UI 에셋 (`FontAwesome`, 커스텀 프리미엄 CSS)
- 데이터 컴포넌트 (`jsTree`, `Tabulator`, `Monaco Editor`)

## 4. 추후 과제 (Possible Improvements)
현재 모든 기능이 원활히 동작하나 도입 시 더욱 효율적인 운영과 고도화를 위해 다음을 추가할 수 있습니다.

1. **에러 핸들링 및 보안 강화**: 현재는 로컬 환경 용도로 만들어졌으므로 허용되어 있지만, 프로덕션 배포 시에는 사용자 권한 관리나 악의적 `DROP` 등을 차단하는 미들웨어 추가 필요.
2. **다크/라이트 라이브 테마 전환**: 우측 상단에 CSS 토글 버튼을 추가하여 테마 전환.
3. **쿼리 기록 (Query History)**: `localStorage`에 최근에 성공한 쿼리들을 저장해 에디터에 다시 불러오기 기능.
4. **결과 Export 기능**: Tabulator의 내장 기능을 활용해 조회된 데이터를 CSV나 Excel로 즉시 다운로드.
