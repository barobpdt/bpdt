🎯 트리 메뉴 예제

화면 왼쪽에 보이는 그라데이션 탭(☰)에 마우스를 올려보세요!

💡 사용 방법

  • 왼쪽 그라데이션 탭(☰)에 마우스를 올리면 메뉴가 나타납니다
  • 화살표(▶)가 있는 메뉴에 마우스를 올리면 하위 메뉴가 펼쳐집니다
  • 메뉴에서 마우스를 떼면 자동으로 숨겨집니다

✨ 주요 기능

  • 트리 구조: 계층적 메뉴 구조로 정보를 체계적으로 정리
  • 호버 효과: 마우스를 올리면 부드럽게 확장
  • 자동 숨김: 메뉴에서 마우스를 떼면 자동으로 숨김
  • 순수 CSS: JavaScript 없이 CSS만으로 구현
