## 🚀 빠른 시작 가이드

### Vercel 배포 (가장 쉬움)
```bash
# 1. Vercel CLI 설치
npm i -g vercel

# 2. 로그인
vercel login

# 3. 배포
vercel
```

### Railway 배포
```bash
# 1. Railway CLI 설치
npm i -g @railway/cli

# 2. 로그인
railway login

# 3. 프로젝트 초기화
railway init

# 4. 배포
railway up
```

### Render 배포
1. GitHub에 코드 푸시
2. Render.com 접속
3. "New Web Service" 클릭
4. GitHub 저장소 연결
5. 자동 배포 완료!
